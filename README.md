##  IMPORTANTE: Ejecución del Proyecto

Por cuestiones de seguridad y buenas prácticas, la API Key de TMDB no está incluida en este repositorio. 

Para poder compilar y ejecutar la aplicación, siga estos pasos:
1. En la raíz del proyecto, busque el archivo `local.properties.template`.
2. Renómbrelo o haga una copia con el nombre `local.properties`.
3. Reemplace el valor genérico con su propia clave de TMDB: 
   `TMDB_API_KEY="REPLACE"`
